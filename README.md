# Arezzz is Buzzzy — vitrine statique

Prête pour une relecture et une publication séparée sur `https://imothepe-arezz.github.io/`. Aucun déploiement effectué par cette préparation.

Six fichiers publics uniquement : `index.html`, `privacy.html`, `terms.html`, `styles.css`, `README.md` et `bee.png`. Pas de dépendance, compilation, JavaScript, compte utilisateur ou serveur applicatif. Le PNG est une copie de l’abeille de marque existante.

## Avant publication

- Relire le texte avec le fonctionnement effectivement activé du projet.
- Conserver la même navigation et les trois pages au même niveau du site.
- Remplacer le commentaire `google-site-verification` dans la page d’accueil par la balise officielle uniquement lorsqu’elle a été émise pour ce domaine. Aucun code de vérification fictif n’est fourni.
- Publier uniquement ces six fichiers. Ne pas ajouter de fichier OAuth, jeton, journal privé, archive vidéo ou code du moteur de publication.
- Vérifier les liens publics, le rendu mobile et les URL de confidentialité/conditions après mise en ligne.

Le contact est uniquement le profil Instagram public. Les archives Drive ne sont pas liées depuis cette vitrine. La politique distingue l’accès YouTube (upload et lecture), l’archivage Drive privé séparé et les connexions Meta lorsqu’elles seront configurées. Le site ne présente ni affiliation, certification, promesse de vues ni offre commerciale.
